# 数据来源

`HaluMem-Medium.jsonl` 是未修改的官方数据文件，2026-10-16 获取。

- 发布者：IAAR-Shanghai / MemTensor Research Group。
- 数据集：https://huggingface.co/datasets/IAAR-Shanghai/HaluMem
- 原文件：https://huggingface.co/datasets/IAAR-Shanghai/HaluMem/resolve/main/HaluMem-Medium.jsonl
- 论文：HaluMem: Evaluating Hallucinations in Memory Systems of Agents，https://arxiv.org/abs/2511.03506
- 许可：CC BY-NC-ND 4.0；许可全文见 `../halumem/LICENSE.txt` 与 https://creativecommons.org/licenses/by-nc-nd/4.0/ 。

原文件摘要记录在 `PUBLISH-MANIFEST.json` 及原运行 `manifest.json`。本仓库仅实际执行首位用户的部分会话，数据集文件包含完整 Medium 数据不代表已经全量评测。
